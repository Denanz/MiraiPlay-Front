# MiraiHub Front

React/Vite фронтенд аниме-сервиса MiraiHub — SPA на вебе и нативное Android-приложение (Capacitor) из одной кодовой базы. Бэкенд — отдельный репозиторий [MiraiHub API](https://github.com/) (edge-шлюз перед публичным аниме-API).

Стек: **React 18 · TypeScript · Vite · Tailwind CSS · React Router · Capacitor (Android)**.

## Возможности

- Каталог с фильтрами (жанры/год/студия/статус/сортировка) и отдельная главная страница (спотлайт + продолжить просмотр + рекомендации по жанрам)
- Собственный HTML5-плеер (рендерится бэкендом, встраивается через iframe): HLS, Aniskip-пропуск опенинга/эндинга, скриншоты в галерею, эпизодические оценки, resume между устройствами
- Совместный просмотр (Watch Together) — комнаты с синхронизацией плеера через WebSocket
- Галерея скриншотов с группировкой по тайтлам и фильтрами по серии/дате
- Ачивки (~110 штук), дневник просмотра, персональная статистика и «Итоги года» (Wrapped)
- Два независимых дизайна на одном коде — Legacy и Modern (переключатель в Настройках, `data-design` + CSS-переменные, ни один экран не завязан на конкретный)
- Домашние Android-виджеты (продолжить смотреть, расписание, стрик, скриншот) без бэкграунд-синхронизации — работают на уже закэшированных данных

## Структура

```text
src/
├── pages/         14 экранов — Главная, Каталог, Тайтл, Просмотр, Плеер, Поиск,
│                  Закладки, Расписание, Ачивки, Галерея, Профиль, Настройки,
│                  Wrapped, История изменений
├── components/    переиспользуемые блоки (карточка релиза, навигация, спотлайт,
│                  рекомендации, продолжить просмотр, модальный плеер-шелл)
├── api/           по одному модулю на домен бэкенда (releases, bookmarks,
│                  episodes, screenshots, together, ratings, diary, schedule…)
├── lib/           дизайн-переключатель, темизация, resume-логика, img-прокси,
│                  синхронизация Android-виджетов
├── store/         авторизация (localStorage-токен Anixart)
└── styles/        Tailwind + отдельный CSS-кит на Modern-дизайн по странице
```

Роутинг с ленивой загрузкой чанков на страницу (`React.lazy`) — держит начальный бандл маленьким.

## Запуск

```bash
npm install
npm run dev      # Vite dev-server
npm run build    # tsc + vite build → dist/
npm run preview  # локальный просмотр собранного билда
```

## Android (Capacitor)

Фронтенд собирается в `dist/` и целиком бандлируется внутрь APK (офлайн, без загрузки веб-страницы по сети):

```bash
npm run build
npx cap sync android
cd android
ANDROID_HOME=<путь к SDK> JAVA_HOME=<путь к JDK 21> ./gradlew assembleDebug --no-daemon
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. `capacitor.config.ts` — `appId: fun.denanz.anime`, `webDir: dist`.

Версионирование (`android/app/build.gradle`): релиз с новой фичей — минорная версия (2.4 → 2.5), только фиксы — патч (2.5 → 2.5.1); `versionCode` всегда монотонно +1. История — `src/lib/changelog.ts` (первая запись = текущая версия, отображается на `/changelog`).

## Конфигурация

Единственная точка входа в бэкенд — `src/api/client.ts` (`baseURL`, гейтвей-ключ, авто-подстановка токена авторизации в каждый запрос). Постеры и скриншоты проксируются через `lib/img.ts`, чтобы реальный IP посетителя не доходил до апстрим-CDN напрямую.
